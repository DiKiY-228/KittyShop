## Реализованный функционал (ПР 1 – ПР 4)

1. **Клиентская часть (ПР 1 и ПР 2):**
   - Семантическая адаптивная верстка страниц (`index.html`, `catalog.html`, `product.html`, `basket.html`, `contacts.html`) с общим файлом стилей `style.css` и подключенным шрифтом `Dela Gothic One`.
   - Подбор средств по типу кожи (сухая, жирная, чувствительная) с поддержкой множественного выбора.
   - Динамическая сортировка товаров по цене (по возрастанию и убыванию) без перезагрузки страницы.
   - Интерактивная карта на странице контактов (`contacts.html`) и валидация формы обратной связи.

2. **Серверная часть и база данных (ПР 3):**
   - REST API на Python (**FastAPI** + **Uvicorn**), отдающее как JSON-данные (`/api/...`), так и статические файлы фронтенда.
   - Реляционная база данных **SQLite** с тремя связанными таблицами и автоматической инициализацией.
   - Безопасное хранение паролей с помощью хеширования **SHA-256 с солью** и защита от SQL-инъекций через параметризованные запросы (`?`).
   - Разграничение доступа: просмотр и изменение корзины доступны только авторизованному пользователю.

3. **Контейнеризация и развертывание (ПР 4):**
   - Приложение упаковано в Docker-контейнер (`Dockerfile`, `requirements.txt`, `amvera.yaml`).
   - Настройки вынесены в переменные окружения (`DB_NAME`, `SECRET_SALT`, `PORT`).
   - Проект развернут на облачной платформе **Amvera** с поддержкой HTTPS и постоянным хранилищем для базы данных.

## Структура базы данных (`database.db`)

База данных создается автоматически при запуске сервера и включает 3 связанные таблицы:

1. **`users`** — учетные записи покупателей:
   - `id` (`INTEGER`, `PRIMARY KEY AUTOINCREMENT`) — уникальный идентификатор пользователя;
   - `username` (`TEXT`, `UNIQUE NOT NULL`) — логин покупателя;
   - `password_hash` (`TEXT`, `NOT NULL`) — SHA-256 хеш пароля с солью.

2. **`products`** — каталог косметических товаров (16 позиций):
   - `id` (`INTEGER`, `PRIMARY KEY AUTOINCREMENT`) — уникальный идентификатор товара;
   - `title` (`TEXT`, `NOT NULL`) — название косметического средства;
   - `description` (`TEXT`) — назначение / тип кожи;
   - `price` (`REAL`, `NOT NULL`) — цена в рублях;
   - `image_url` (`TEXT`) — относительный путь к изображению товара (`images/...`).

3. **`cart`** — персональная корзина покупателей:
   - `id` (`INTEGER`, `PRIMARY KEY AUTOINCREMENT`) — идентификатор позиции в корзине;
   - `user_id` (`INTEGER`, `NOT NULL`, `FOREIGN KEY -> users(id)`) — внешний ключ на таблицу пользователей;
   - `product_id` (`INTEGER`, `NOT NULL`, `FOREIGN KEY -> products(id)`) — внешний ключ на таблицу товаров;
   - `quantity` (`INTEGER`, `DEFAULT 1`) — количество единиц товара.

## Основные API-эндпоинты

- `GET /api/products` — получение полного списка товаров каталога.
- `GET /api/products/{product_id}` — получение подробной информации о конкретном товаре по ID.
- `POST /api/register` — регистрация нового пользователя.
- `POST /api/login` — авторизация пользователя.
- `GET /api/cart` — получение содержимого корзины текущего пользователя (по заголовку `user-id`).
- `POST /api/cart` — добавление товара в корзину текущего пользователя.

## Переменные окружения

Настройки приложения задаются через переменные окружения (шаблон приведен в `.env.example`):

- `DB_NAME` — путь к файлу базы данных SQLite (по умолчанию `data/database.db`).
- `SECRET_SALT` — секретная строка для хеширования паролей.
- `PORT` — порт запуска веб-сервера (по умолчанию `8000`).

## Инструкция по запуску

### Вариант 1. Запуск в Docker (рекомендуемый)

1. Соберите Docker-образ из корня проекта:
   ```bash
   docker build -t kittyshop .
   ```
2. Запустите контейнер с передачей переменных окружения:
   ```bash
   docker run -d -p 8000:8000 -e DB_NAME=data/database.db -e SECRET_SALT=my_secret_salt --name kittyshop-app kittyshop
   ```
3. Откройте приложение в браузере: `http://localhost:8000`.

### Вариант 2. Локальный запуск через Python

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер FastAPI:
   ```bash
   uvicorn main:app --reload
   ```
3. Перейдите в браузере по адресу `http://localhost:8000`.
